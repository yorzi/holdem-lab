# Holdem Lab roadmap

This is a local-first, MIT-licensed educational project. Work is maintainer-led;
this roadmap is not a delivery schedule or a hosted-service promise.

## Current baseline

- Rails 8.1, SQLite, Vite Ruby, React and a pure TypeScript heads-up rules engine.
- Seeded 100BB virtual-chip hands, legal actions, showdown and versioned replay.
- English and independently authored Chinese lessons for Position, Pot Odds and
  Decision Quality, plus card-recognition drills and a browser-local review queue.
- Native Rails accounts, profile, owner-scoped export and account deletion.
- Versioned content manifests, provenance registries, mirrors and publication gates.
- Explicit development/test import; production import and default analytics disabled.

## Useful next contributions

- Reproducible rules/evaluator bugs, with seeds and regression tests.
- Accessibility improvements and manual assistive-technology evidence.
- Clearer source-backed lesson explanations and independent domain review.
- Better local setup and contributor onboarding from real fresh-machine reports.
- Data lifecycle and browser-local export/deletion improvements before cloud sync.

## Separate evidence gates

Some asset manifests record owner approval; source packets still require
independent domain review. Automated tests do not establish learning outcomes,
external rights, production security, backup recovery, or mail delivery.

Cross-device sync, production import, payments, advanced strategy data and
multi-player rules require separate designs and evidence. They are not implied
by existing models, interfaces, or this roadmap. Real-money play, live-table
assistance, HUDs, automated betting and redeemable prizes are outside scope.
