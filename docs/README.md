Code and tests define behavior. [AGENTS.md](../AGENTS.md) records engineering
constraints. [Local validation records](../.logs/) are dated evidence, not a
claim of current remote CI, independent review, hosted availability or learning
outcomes. Keep one guide per topic and update it alongside behavior changes.

The repository intentionally excludes historical prototypes, private deployment
material, internal business plans and old operational logs. Original rules,
evaluator and replay versions remain explicit; a new project name does not
silently change game behavior or promote content review status.
